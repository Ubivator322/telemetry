Сбор телеметрии из 4 источников

Что делает программа:
- читает telemetry.json (300 тиков, 4 источника, по 100..600 объектов за тик);
- у каждого объекта тип scalar (число) или bool (true/false);
- валидные значения пишет в таблицу telemetry;
- невалидные значения пишет в таблицу invalid_log;
- тренды trend_1..trend_20 пишет в таблицу trends;
- перед записью тренда делает запись в самописный WAL (таблица wal);
- в окне показывает последние 3600 событий трендов.

Запуск через run.bat:
1. Запустить run.bat.
2. Скрипт сам скачает sqlite-jdbc и org.json в папку lib (если их нет),
   найдёт JDK в PATH, JAVA_HOME или %USERPROFILE%\.jdks,
   скомпилирует проект и запустит Main.
3. При первом запуске создастся telemetry.json, затем telemetry.db.

Запуск в IntelliJ IDEA:
1. Открыть папку telemetry.
2. Пометить папку src как Sources Root.
3. Добавить в Libraries файлы:
   lib\sqlite-jdbc-3.53.4.0.jar
   lib\json-20240303.jar
4. Запустить Main.

Важно:
- База telemetry.db при каждом запуске пересоздаётся.
- Рабочая папка должна быть корнем проекта (там, где лежит telemetry.json).
- Если telemetry.json ещё нет, программа создаст его сама.
- Программа запускается с -Xmx1g. Если не хватит памяти, увеличь это значение в run.bat.

Portable-версия (без установленной Java):
1. Папка portable уже содержит встроенную Java.
2. Запустить portable\run-portable.bat.
3. Java на компьютере не нужна. Только Windows x64.
4. Папки portable\runtime, portable\app и portable\lib не разбирать.
5. Папку portable можно скопировать целиком на другой компьютер.

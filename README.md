# Telemetry Collector

Учебный проект на Java: сбор телеметрии из 4 источников, проверка значений, запись в SQLite и наглядное окно на Swing.

Данные приходят в виде JSON-файла на 300 «секунд». Каждую секунду 4 источника присылают по 100–600 уникальных объектов из 1000 предопределённых. Часть значений специально битая — она уходит в лог, валидные пишутся в базу. Тренды дополнительно проходят через самописный WAL.

## Быстрый запуск

### Вариант 1 — без установленной Java (Windows x64)

```
portable\run-portable.bat
```

Внутри `portable` уже лежит встроенная Java (`jlink`-рантайм). Ничего ставить не нужно — просто скопируй папку целиком на любой Windows x64.

### Вариант 2 — с установленным JDK

```
run.bat
```

Скрипт сам:
- находит JDK (PATH → `JAVA_HOME` → `%USERPROFILE%\.jdks`);
- скачивает `sqlite-jdbc` и `org.json` в `lib`, если их нет;
- компилирует `src` в `out`;
- запускает `Main`.

### Вариант 3 — IntelliJ IDEA

1. Открыть папку проекта.
2. `src` уже помечена как Sources Root.
3. Библиотеки из `lib` уже подключены (`.idea/libraries`).
4. Запустить `Main`.

После запуска в окне нажать **«Старт»**.

## Что происходит при запуске

```
JsonGenerator.generate()
      ↓
telemetry.json  (300 тиков × 4 источника × 100..600 объектов)
      ↓
чтение файла → JSONObject → JSONArray "ticks"
      ↓
таймер каждые 50 мс → nextTick()
      ↓
                 ┌── валидное ──→ telemetry
Measurement ─────┤
                 └── невалидное → invalid_log

валидное + имя trend_* ──→ wal (сначала) ──→ trends
                              ↓
                     окно в памяти на 3600 событий
      ↓
commit() раз в тик → после 300 тиков finish()
```

## Правила валидации

| Тип | Валидно | Невалидно |
|---|---|---|
| `scalar` | число, точка или запятая (`53.9`, `53,9`) | `bad`, `NaN`, `Infinity` |
| `bool` | `true` / `false` в любом регистре | `maybe`, `1`, пустая строка |

## Структура проекта

```
src/
  Main.java              точка входа
  TelemetryWindow.java   Swing-окно, таймер, счётчики, окно 3600
  Measurement.java       одно измерение + isValid() / isTrend()
  Trends.java            20 предопределённых трендов
  Database.java          SQLite: 4 таблицы + самописный WAL
  JsonGenerator.java     генератор telemetry.json
lib/                     sqlite-jdbc, org.json
portable/                версия со встроенной Java
  runtime/               jlink-рантайм (Java 26)
  app/                   скомпилированные классы
  lib/                   библиотеки для portable
  run-portable.bat
run.bat
```

## Таблицы в `telemetry.db`

| Таблица | Назначение |
|---|---|
| `telemetry` | все валидные значения |
| `invalid_log` | все невалидные значения |
| `trends` | только тренды `trend_1..trend_20` |
| `wal` | журнал операций над трендами (пишется до вставки) |

Поля: `id`, `ts`, `source`, `name`, `type`, `value`. У `wal` вместо этого `ts`, `operation`, `payload`.

База **пересоздаётся при каждом запуске** (`DROP TABLE IF EXISTS` перед `CREATE`), чтобы прогоны не смешивались. `telemetry.json` создаётся один раз и переиспользуется.

Посмотреть результат можно в IntelliJ IDEA: **Database → + → Data Source → SQLite** и указать путь к `telemetry.db`.

## Результат полного прогона

```
Всего:       418925
Валидных:    376910
Невалидных:   42015   (~10%)
Трендов:       7600
Окно трендов:  3600   (уперлось в предел)
```

Трендов больше 6000, потому что уникальность соблюдается внутри каждого источника отдельно — один и тот же `trend_5` может прийти от нескольких источников в одном тике.

## Особенности реализации

- **PreparedStatement** — запросы готовятся один раз, значения подставляются через `?`.
- **Ручные транзакции** — `setAutoCommit(false)`, `commit()` один раз за тик, а не на каждую строку.
- **WAL — таблица, а не механизм** — журнал пишется до вставки в `trends`, но восстановление (replay) намеренно не реализовано.
- **Окно 3600 — только в памяти** — в базе хранятся все тренды, в списке последние 3600.
- **Всё в одном потоке** — `Swing Timer` работает в потоке интерфейса, поэтому окно может слегка подтормаживать во время прогона.

## Требования

- **portable** — Windows x64, Java не нужна.
- **run.bat / IntelliJ** — JDK 17+ (проект собран на JDK 26).
